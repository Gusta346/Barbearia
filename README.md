# Prototipo de Barbearia

Este projeto é um protótipo de um site de barbearia desenvolvido com **HTML**, **CSS** e **JavaScript**. O objetivo deste protótipo é criar uma experiência simples e funcional para os usuários interagirem com os serviços de uma barbearia, como agendamento de horários e visualização dos serviços oferecidos.

---

## Tecnologias Utilizadas

- **HTML**: Estrutura básica da página.
- **CSS**: Estilização e design responsivo.
- **JavaScript**: Funcionalidade interativa, como o agendamento de serviços.

---

## Funcionalidades

- **Design Responsivo**: O layout se adapta a diferentes tamanhos de tela (desktop, tablet e celular).
- **Interatividade**: Através de JavaScript, é possível interagir com o conteúdo da página, como escolher os serviços ou visualizar informações adicionais.
- **Agendamento de Serviços**: O usuário pode agendar horários para cortes ou outros serviços oferecidos pela barbearia.
